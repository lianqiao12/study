# 个人知识库 Vault

一个用 **Obsidian** 管理、**Git + GitHub** 备份的个人知识库。本文档同时作为仓库说明与知识库入门指南。

---

## 一、为什么要建个人知识库（目的）

1. **把脑子外包**：人的工作记忆有限，把信息落到文字，释放脑力去思考而非记忆。
2. **知识复利**：零散笔记通过"链接"连成网络，长期积累后产生 1+1>2 的洞见（即"第二大脑"）。
3. **对抗遗忘**：写下来的东西可检索、可追溯，比收藏夹/微信收藏可靠得多。
4. **输出驱动输入**：为了写清楚，你会逼自己真正理解；写作即思考。
5. **版本与资产**：用 Git 保存，每一次修改都有历史，知识变成可传承的个人资产。

> 核心心法：知识库不是"笔记本"，而是"自己和外脑之间的对话系统"。重在**持续记录 + 建立连接**，而非一次性整理完美。

## 二、如何入门：创建你的个人知识库（以 Obsidian 为例）

### 2.1 为什么选 Obsidian

- **本地优先**：笔记就是纯文本 `.md` 文件，存在自己硬盘上，不绑定厂商、不怕停服。
- **双向链接**：用 `[[笔记名]]` 把两篇笔记连起来，自动生成反向链接。
- **关系图谱**：把所有笔记画成网络，直观看到知识结构与"隐性关联"。
- **插件生态**：Dataview、Templater、Canvas 等可大幅扩展（按需启用，不必贪多）。
- **免费、跨平台**：Windows / macOS / Linux / 移动端均可。

### 2.2 安装与创建仓库（Vault）

1. 到 https://obsidian.md 下载并安装。
2. 首次打开选 **"创建新 vault"**，指定一个本地文件夹（本仓库即 `ObsidianVault`）。
3. 之后所有笔记都会以 `.md` 文件落在这个文件夹里——它就是一个普通文件夹，可用文件管理器直接查看。

### 2.3 必须掌握的核心概念

| 概念 | 写法 | 作用 |
| --- | --- | --- |
| 笔记 | `我的笔记.md` | 一篇 Markdown 文档 |
| 双向链接 | `[[另一篇笔记]]` | 在笔记间建立连接，自动形成图谱 |
| 标签 | `#项目/进行中` | 跨文件夹分类，便于检索与图谱着色 |
| 标题 | `# 一级标题` | 文档结构 |
| 文件夹 | `项目/`、`Go/` | 粗粒度归类（见下方目录结构） |
| 代码块 | ` ``` ` | 写代码、配置片段 |

### 2.4 推荐的知识组织方法

- **Zettelkasten（卡片盒）**：每条想法写成一张"原子笔记"，用链接串联，而非按大主题堆砌。
- **PARA 法**：用四个顶层文件夹组织——
  - `Projects` 项目（有截止期的）
  - `Areas` 领域（长期负责的，如"健康""工作"）
  - `Resources` 资源（感兴趣的主题素材）
  - `Archives` 归档（不再活跃的内容）

> 本仓库的 `00-索引 / 容器 / 通信 / 项目 / Go / skills` 即按主题划分，你可按自己的 PARA 思路调整。

### 2.5 入门日常习惯（从小开始）

1. 开一篇"首页/索引"笔记，列出常用入口（本仓库用 `00-索引`）。
2. 每天随手记：读书摘抄、想法、报错解决过程，都用 `[[链接]]` 串起来。
3. 每周花 10 分钟回看并补链接，结构会自然浮现。
4. 不必追求完美分类，**先写，再连，最后才整理**。

### 2.6 实用设置建议

- 开启 `设置 → 核心插件 → 每日笔记 / 关系图谱 / 标签面板`。
- 图谱里按文件夹/标签加"颜色分组"，提升区分度（见第四节）。
- 插件按需装：检索用 `Dataview`，模板用 `Templater`，画板用 `Canvas`。

## 三、如何用 GitHub 保存 / 同步个人知识库

### 3.1 为什么用 GitHub

- **自动备份**：笔记不再只在一台电脑上，丢了也能恢复。
- **版本历史**：每次提交都是快照，可回到任意历史版本。
- **多端同步**：家里/公司/笔记本 `git pull` 一份即可。
- **私有可控**：仓库可设为 Private，仅自己可见。

### 3.2 准备工作

1. 注册 GitHub 账号：https://github.com
2. 本机安装 Git：https://git-scm.com （安装时一路默认即可）
3. 配置身份（只需一次）：
   ```bash
   git config --global user.name  "你的名字"
   git config --global user.email "你的邮箱"
   ```

### 3.3 新建仓库并连接

在 GitHub 网页上 `New repository` → 取名（如 `study`）→ 选 **Private** → 不要勾选自动生成 README → 创建。

连接方式有两种，本机**推荐 SSH**（原因见下）：

#### HTTPS（最简单，但本机 443 被挡）
```bash
git remote add origin https://github.com/用户名/仓库名.git
```

#### SSH（本机环境 443 端口不通，已采用此方式）
1. 生成本机密钥（已执行过可跳过）：
   ```bash
   ssh-keygen -t ed25519 -C "你的邮箱"
   # 一路回车，密钥存于 ~/.ssh/id_ed25519
   ```
2. 把公钥内容加到 GitHub：`Settings → SSH and GPG keys → New SSH key`，粘贴 `~/.ssh/id_ed25519.pub` 全文。
3. 测试连通：
   ```bash
   ssh -T git@github.com
   # 看到 "Hi 用户名!" 即成功
   ```
4. 设置远程为 SSH 地址：
   ```bash
   git remote set-url origin git@github.com:用户名/仓库名.git
   ```
   > 本仓库当前远程：`git@github.com:lianqiao12/study.git`

### 3.4 首次提交与日常流程

**首次推送**（仓库刚建好时）：
```bash
git add -A
git commit -m "init: 初始化知识库"
git push -u origin main
```

**之后每天**（增删改笔记后）：
```bash
git add -A
git commit -m "更新：补充 XX 主题笔记"
git push origin main
```

**换设备 / 拉取最新**：
```bash
git pull --tags origin main
```

> 提交信息用中文没问题；想规范可参考 `feat / fix / docs / update` 前缀。

### 3.5 .gitignore 建议

本仓库已有 `.gitignore` 忽略 Obsidian 回收站：
```
.trash/
```
如需进一步排除"个人窗口布局"（避免多端布局冲突），可追加：
```
.obsidian/workspace.json
```
其余 `.obsidian/*.json`（含图谱配色 `graph.json`）建议**保留提交**，以便配置随仓库同步。

### 3.6 多端同步与协作

- **另一台电脑**：`git clone git@github.com:用户名/仓库名.git` 后用 Obsidian 打开该文件夹即可。
- **回退版本**：`git log` 找提交号，`git checkout <号>` 或 `git revert <号>`。
- **协作**：Private 仓库可邀请协作者；或用 GitHub Pages 把公开部分做成网站。
