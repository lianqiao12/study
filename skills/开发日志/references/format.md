# 开发日志格式约定

开发日志位于知识库根目录的 `开发日志/`,一个文件记录一天。

## 文件命名

`开发日志/YYYY-MM-DD.md`(如 `2026-09-01.md`)。文件由 `scripts/add_devlog.py`
自动创建,无需手建。

## 单文件结构

```
# 开发日志 2026-09-01

> 每日记录开发进展。条目按时间倒序追加,最新在最上方。

## 14:30

- 把仓库 remote 从 HTTPS 切到 SSH,绕开 443 被挡
- 给 Graph View 配了按文件夹分组配色

## 09:15

- 修复了登录超时问题(根因:token 过期未刷新)
```

- 一级标题:`# 开发日志 <日期>`
- 每个条目:`## HH:MM` 时间点 + 若干 `- 要点` 子弹
- 同一天多次触发,新条目插到最上方(最新在上)
- 引用相关笔记用 `[[双链]]`,如 `[[知识库更新]]`,便于图谱串联

## 写法约定

- 每个要点一句话,动词开头,聚焦"做了什么 / 结果"。
- 踩坑类写"现象 → 根因 → 修复"三短句。
- 不写废话,聚焦可复用、可检索的开发产出。
