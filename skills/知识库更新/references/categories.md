# 分类与标签约定

## 分类目录(数字前缀用于排序)

| 目录 | 用途 | 示例 |
|------|------|------|
| `00-索引/` | 仅放 `首页.md`,索引地图 | 首页.md |
| `10-项目笔记/` | 具体项目的解读、架构、模块说明 | ai-resume 项目架构.md |
| `20-技术概念/` | 与具体项目解耦的通用技术原理 | SSE 流式通信.md |
| `30-踩坑记录/` | 问题→根因→修复的复盘 | docker-compose 路径错位导致 make up 失败.md |
| `40-学习路线/` | 学习项目如何接手、从哪写起 | ai-resume 学习接手路线.md |

新增分类时,沿用 `NN-名称/` 前缀,并在首页的"索引"区块登记。

## 标签体系

- `#项目/ai-resume` — 与 ai-resume 项目相关
- `#概念/通信` — 通信类(SSE、事件协议等)
- `#概念/容器` — Docker / Compose 等
- `#踩坑` — 任何踩坑复盘
- `#学习` — 学习路线、接手指南

笔记首行标题下紧跟一行 `#标签`,可叠加多个。

## 命名

- 笔记文件名:中文短句,能当 `[[双链]]` 锚点,例如
  `Docker Compose 相对路径陷阱.md`。
- 双链引用用文件名的主体(去掉 `.md`),例如 `[[Docker Compose 相对路径陷阱]]`。
