# Go 切片 Slice 是什么、怎么用

#概念/Go #Slice #切片

> 切片（Slice）是 Go 中最常用的「可变长序列」类型。它**不是数组**，而是**对底层数组的一段连续引用**——带一个指针、长度和容量。

## 1. 什么是切片：底层是个「三件套」

切片在运行时是一个结构体（伪代码）：

```go
type slice struct {
    ptr *Elem   // 指向底层数组的某个元素
    len int     // 当前长度（能直接访问的元素个数）
    cap int     // 容量（从 ptr 到数组末尾的元素个数）
}
```

- **数组**长度固定，是值类型；**切片**长度可变，是引用语义（共享底层数组）。
- 多个切片可以**指向同一底层数组**的不同区间。

```go
arr := [5]int{0,1,2,3,4}
s1 := arr[1:4]   // [1 2 3]  len=3 cap=4  (指向 arr[1])
s2 := arr[2:5]   // [2 3 4]  len=3 cap=3  (指向 arr[2])
// s1 和 s2 共享 arr 这个底层数组
```

## 2. 怎么创建

| 方式 | 写法 | 说明 |
|------|------|------|
| 字面量 | `s := []int{1,2,3}` | 最常用，字面量前**没有长度**才是切片 |
| `make` | `s := make([]int, 3)` | 长度3、容量3、零值 |
| `make` 指定容量 | `s := make([]int, 3, 5)` | len=3 cap=5 |
| 从数组/切片截取 | `s := arr[1:4]` | 共享底层数组 |
| `nil` 切片 | `var s []int` | len=0 cap=0 ptr=nil |

> 易混点：`[3]int` 是数组，`[]int` 是切片。函数参数尽量用切片，数组会整体拷贝。

## 3. len 与 cap

```go
s := make([]int, 3, 5)
len(s) // 3  —— 能直接下标访问的范围 [0,len)
cap(s) // 5  —— 底层数组从 ptr 起还能扩到的上限
```

- `s[i]` 只能访问 `0 <= i < len(s)`；越界 panic。
- `cap` 决定了**不重新分配**能 append 多少。

## 4. 截取（s[low:high]）

```go
s := []int{0,1,2,3,4}
t := s[1:3]   // [1 2]  len=2 cap=4 (从 s[1] 到数组末尾)
```

- `s[low:high]` 取 `[low, high)`，**容量变为 `cap(s)-low`**。
- **坑：t 和 s 共享底层数组**，改 `t[0]` 会影响 `s[1]`。

## 5. append 与扩容

```go
s := []int{1,2,3}
s = append(s, 4)        // [1 2 3 4]，cap 够则原地追加
s = append(s, 5, 6)     // 容量不够 → 分配新底层数组，ptr 改变
```

- `append` **可能返回新数组**：当 `len+追加数 > cap` 时，Go 分配更大的底层数组并拷贝，原切片与新切片**不再共享**。
- **扩容策略（大致）**：cap < 256 时约翻倍；≥256 时按约 1.25 倍增长（不同 Go 版本略有差异）。不要依赖精确倍数。
- 习惯：`s = append(s, x)` 一定要**接回返回值**，否则若发生扩容，原变量仍指向旧数组。

## 6. 空切片 vs nil 切片

```go
var a []int        // nil 切片：ptr=nil, len=0, cap=0
b := []int{}       // 空切片：ptr 非 nil, len=0, cap=0
c := make([]int,0) // 空切片
```

- `len(a)==len(b)==0`，但 `a == nil` 为 true，`b == nil` 为 false。
- JSON 序列化：`nil` 切片 → `null`，空切片 → `[]`。**若要返回空数组而非 null，用 `b`**。
- 判断「有没有元素」用 `len(s)==0`，不要用 `s == nil`（空切片也会误判）。

## 7. copy

```go
dst := make([]int, len(src))
n := copy(dst, src)   // 拷贝 min(len(dst),len(src)) 个元素，返回实际拷贝数
```

- `copy` 不会分配新数组，也不会改 cap；只按目标长度覆盖。

## 8. 常见坑

### 8.1 截取导致的内存泄漏
```go
big := make([]byte, 1<<20)   // 1MB
small := big[:10]            // 只取 10 字节，但 small 的 cap 仍是 1MB
// → 整个 1MB 数组因 small 存活而无法被 GC 回收
```
**解决**：用 `copy` 复制出独立小切片：
```go
small := make([]byte, 10)
copy(small, big[:10])        // 引用断开，大数组可释放
```

### 8.2 子切片互相影响
见 §4：`t := s[1:3]` 后改 `t[0]` 会改到 `s[1]`。需要隔离就用 `copy`。

### 8.3 append 后别名失效
```go
a := []int{1,2,3}
b := a[:2]        // [1 2]，共享
a = append(a, 4)  // a 扩容 → 新数组
b[0] = 99         // 改的是旧数组，a[0] 不受影响
```
扩容前共享、扩容后分道扬镳，容易踩。

### 8.4 range 取地址
见 [[Go for range 遍历#坑]]：老版本 Go 循环变量是同一个地址；只读元素没问题，取 `&e` 要注意（Go 1.22+ 已每轮新建循环变量，此坑基本消除）。

## 9. 二维切片

```go
// 行数固定、列数相同
matrix := make([][]int, 3)
for i := range matrix {
    matrix[i] = make([]int, 4)   // 每行独立底层数组
}
```
- 内层每行是独立切片，便于不规则（锯齿）二维结构。

## 10. 实用技巧

- 删除第 i 个元素：`s = append(s[:i], s[i+1:]...)`
- 头部删除：`s = s[1:]`
- 尾部弹出：`x, s = s[len(s)-1], s[:len(s)-1]`
- 预分配容量避免频繁扩容：`make([]T, 0, knownSize)`
