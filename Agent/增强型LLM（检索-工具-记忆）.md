# 增强型 LLM（检索-工具-记忆）

> 标签：#概念/Agent #增强型LLM #Augmented-LLM #检索 #工具 #记忆

## 1. 所有模式的基石

Anthropic 在《Building Effective Agents》中强调：**所有 Agent / Workflow 模式的基础，都是「增强型 LLM」（Augmented LLM）**。

所谓增强型 LLM，是指在基础模型之上集成了三类能力的 LLM：

- **检索 Retrieval**：从外部知识源取回相关信息
- **工具 Tools**：调用函数、API、代码执行器
- **记忆 Memory**：决定保留哪些历史信息、何时遗忘

模型不再是「纯文本生成器」，而是能**主动生成搜索查询、选择工具、决定保留信息**的节点。

## 2. 检索（Retrieval）

- 让模型在生成前先「查资料」，弥补参数化知识的时效性与准确性不足
- 典型形态即 **RAG（检索增强生成）**：把文档切块 → 向量化 → 检索 → 拼进上下文
- 与 [[记忆 Memory]] 的区别：检索偏向「按需外部取回」，记忆偏向「持续保存状态」

## 3. 工具（Tools）

- 模型输出结构化调用指令（如 JSON），由运行时解析并执行
- 工具极大扩展了 LLM 的能力边界：算数、实时数据、写文件、跑代码、操作浏览器
- 关键不在「能不能调」，而在「接口设计得好不好」—— 见 [[构建最佳实践#3. 精心制作 Agent-计算机接口 ACI]]

## 4. 记忆（Memory）

- 模型需要记住对话历史、任务进度、用户偏好
- 分为短期（上下文窗口内）与长期（外部存储）—— 详见 [[记忆 Memory]]

## 5. 设计要点

> 增强型 LLM 的质量，往往不取决于「模型多大」，而取决于 **工具定义是否清晰、记忆是否可用、检索是否精准**。

实践上：先把这些基础能力打磨好，再谈上层编排模式（[[智能体架构模式（Workflow与Agent）]]）。
