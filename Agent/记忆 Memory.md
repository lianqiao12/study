# 记忆 Memory

> 标签：#概念/Agent #记忆 #Memory #向量库 #MIPS #RAG

## 1. 记忆的三层模型（Lil'Log 映射）

| 记忆类型 | 对应实现 | 容量 |
|----------|----------|------|
| **感官记忆 Sensory** | 原始输入（文本/图像）的嵌入表示 | 瞬时 |
| **短期记忆 STM** | 上下文学习（In-context learning），即放在 prompt 里 | 受 Transformer 窗口限制（类比「约 7 项、20-30 秒记忆」） |
| **长期记忆 LTM** | 外部向量存储，查询时检索 | 近乎无限 |

## 2. 短期记忆

- 就是当前对话/任务的上下文窗口内容
- 受 LLM 最大 token 数硬限制
- 做法：把历史消息、工具结果、任务说明直接拼进 prompt
- 痛点：窗口满了怎么办 → 需要**摘要压缩**或**移入长期记忆**

## 3. 长期记忆（外部存储）

- 把信息以**嵌入向量**形式存入向量数据库
- 需要时做**最大内积搜索（MIPS）**，把相关内容取回拼进上下文
- 常用近似最近邻（ANN）算法加速：

| 算法 | 思路 |
|------|------|
| **LSH** | 局部敏感哈希，按相似度分桶 |
| **ANNOY** | 随机投影树 |
| **HNSW** | 分层可导航小世界图（最常用、快） |
| **FAISS** | 基于聚类的向量量化（Facebook） |
| **ScaNN** | 各向异性向量量化（Google） |

## 4. 记忆与 RAG

- 长期记忆的「检索」实际上就是 RAG 的核心
- 区别视角：RAG 强调「检索增强生成」的管线，记忆强调「Agent 跨步骤/跨会话保有状态」
- 与 [[增强型LLM（检索-工具-记忆）]] 中的 retrieval 一脉相承

## 5. 实践要点

- 短期记「当前进展」，长期记「可复用知识/用户画像」
- 检索质量决定 Agent 智商上限：向量表征力弱于全注意力，需配合重排（re-rank）
- 注意隐私：长期记忆可能沉淀敏感信息，需清理机制
